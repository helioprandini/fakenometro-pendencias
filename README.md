# Pendências do Fakenômetro

Painel na lateral do app do Claude com os quadros de pendências do cockpit do Fakenômetro.
Lê e grava no servidor do projeto; cada pessoa usa a própria chave do cockpit, pedida na instalação
e guardada só no computador dela. Este repositório não contém chave nem dado.

No app do Claude: + ao lado da caixa de mensagem → Plugins → Adicionar marketplace `helioprandini/fakenometro-pendencias` → adicionar o plugin `pendencias`.
